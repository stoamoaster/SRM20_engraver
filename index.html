SRM-20 Engraver

Plate with text and logo → G-code → milling machine
Workpiece
no contour loaded

Closed outline in mm. The lower left corner of the outline becomes the origin.

Origin X/Y = lower left corner, Z = top surface of the workpiece.

Red area = clamping fixture. The machine never moves through it (not even during rapid moves – they are routed around it above the workpiece). The finished G-code is checked as well; if anything lies inside the red area, nothing is sent. At the start, the machine always moves to the VIEW position first (Z up first, then X/Y).

Text

Height = height of capital letters. The text is centred horizontally; “Bottom distance” is measured to the lowest point (including g, p, y).

Logo
no logo loaded

SVG, DXF or DWG. Automatically fitted into the free space above the text. Standard logos live in the logos/ folder of the program – simply copy files there.

Milling
Cutting parameters

VIEW/park position in mm in the selected coordinate system (G54 …), i.e. relative to the set origin. Default = VIEW position of the SRM-20. Every program always moves there first (Z up first, then X/Y) and only then to the workpiece.

In VPanel beforehand: command set NC code, select G54 (or the one chosen here) as coordinate system at the top, then set the X/Y origin to the lower left corner and the Z origin to the top surface. Cancel via VPanel or the VIEW button on the machine.
