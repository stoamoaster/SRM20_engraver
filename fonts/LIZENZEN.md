# Schriften

Alle Schriften in diesem Ordner sind Single-Line-Schriften (eine Linie pro Strich, keine Umrisse)
und stehen unter der **SIL Open Font License 1.1** (Volltext: [OFL.txt](OFL.txt)).
Sie dürfen frei benutzt und mit diesem Programm weitergegeben werden, aber nicht einzeln verkauft werden.

| Datei | Schrift | Herkunft |
|---|---|---|
| `ReliefSingleLine.svg` | Relief SingleLine (SVG, offene Pfade) | © 2021–2022 The Relief SingleLine Project Authors – https://github.com/isdat-type/Relief-SingleLine |
| `EMSReadability.svg` | EMS Readability | SVG-Umsetzung: Sheldon B. Michaels / Windell H. Oskay (Evil Mad Scientist), nach *Source Sans Pro Light* von Paul D. Hunt, Adobe |
| `EMSTech.svg` | EMS Tech | Evil Mad Scientist, nach einer Schrift von Kimberly Geswein |
| `EMSOsmotron.svg` | EMS Osmotron | Evil Mad Scientist, nach einer Schrift von Matt McInerney (The League of Moveable Type) |
| `EMSAllure.svg` | EMS Allure | Evil Mad Scientist, nach einer Schrift von Rob Leuschke (TypeSETit) |

Die EMS-Schriften stammen aus der Hershey-Text-Erweiterung von Inkscape
(https://gitlab.com/inkscape/extensions, Ordner `svg_fonts`). Name und Lizenz stehen jeweils im `<metadata>`-Block der Datei.

Die Hershey-Schriften (Futura, Roman, Times …) kommen aus dem Python-Paket `Hershey-Fonts` und sind gemeinfrei.
